# Design concept — Студия Красоты Рим | Фира про Волосы

## Client / project

- Name: Студия Красоты Рим | Фира про Волосы (Красноуральск)
- Date: 2026-11-25
- Niche: локальная студия окрашивания / стрижки / наращивания + внутреннее обучение парикмахеров
- Concept-ID: `2026-11-25-rim-plaque-roads-typographic-v1`
- Composition-archetype: `typographic-poster`
- Forbidden-for-this-niche: quiet-luxury black/cream/gold; cream `#F4F1EA`+terracotta; dark-atelier Лак&Мусс; hero+3 feature cards; purple gradients; spa megacorp; клон Marco Ambrosi dark/gold
- Delta-from-previous: n/a (first concept)

## Niche fingerprint

- Ритуал: запись через YClients / VK; приход на окрашивание или модель на семинар; «все дороги ведут в РИМ»
- Материалы: ножницы, фольга, пигмент, пряди, травертиновая плита лого, кремовые посты VK
- Место / свет: студия на Ленина 20, Красноуральск; дневной / мягкий студийный свет; светлая обложка VK
- Vernacular: #ВсеДорогиВедут_в_РИМ, «Фира про Волосы», семинар по базе окрашивания, модели с седыми корнями / блондом
- Sensory: тепло плиты-камня, шум фена, запах красителя, юмор в постах, не холодный luxury-spa

## Unique thesis

1. Mood: светлый травертин + римская вывеска; дороги сходятся в студию.
2. Type: Newsreader (плита / display) + Outfit (UI) — продолжает рамку serif-лого, не Cormorant/Manrope.
3. Palette: камень `#C8B8A4`, штукатурка `#E8E0D4`, ink `#2A2622`, пепел блонда из фото — без gold и `#F4F1EA`+terracotta.
4. Composition: typographic-poster — плита РИМ = hero-signal; одна фраза; волос edge-to-edge справа.
5. Motion: появление плиты, лёгкий drift пряди, линия «дорог» к главам — 2–3 жеста.
6. Main gesture: рамка-плита «РИМ» в центре первого экрана; «дороги» = навигация услуг/обучения.

## Anti-clone checklist

- [x] Carryover: не dark-atelier / Cormorant+copper Лак&Мусс; не Syne/russet Лисица; не Oswald rows Gretta
- [x] Benchmark clone: Marco Ambrosi = craft фото/CTA only; не тёмный gold hero и не их структура
- [x] AI clusters: не purple; не cream+terracotta; не broadsheet; не hero+3 cards; не quiet-luxury black/cream/gold
- [x] Brand test: без лого остаются плита-жест + волосы + обучение/дороги → ниша hair studio, не юрист/детейлинг/пекарня
